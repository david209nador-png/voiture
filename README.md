# VROOM — Le garage des passionnés

Site vitrine responsive de voitures avec carrousel interactif, recherche, filtres par marque et favoris enregistrés dans le navigateur.

## Voir le site

Ouvre `index.html` dans un navigateur. Le site est statique et ne nécessite ni installation ni compilation.

## Fonctionnalités

- Carrousel de voitures navigable au swipe, aux flèches et au clavier.
- Illustrations automobiles SVG stylisées avec couleurs par modèle.
- Catalogue filtrable par marque et recherche par modèle.
- Favoris sauvegardés localement dans le navigateur.
- Mise en page responsive pour mobile et ordinateur.
